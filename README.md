# Health-Map-AI-Sulawesi-Tenggara
Health Map AI merupakan proyek machine learning untuk memprediksi jumlah tenaga medis di Sulawesi Tenggara menggunakan data jumlah penduduk dan tenaga medis tahun 2015–2025. Data 2015–2024 digunakan untuk training dan 2025 untuk testing, dengan algoritma Linear Regression dan Random Forest Regression.
